CORE PURPOSE OF INNDOS

A unified platform connecting:

🏢 Owners, Landlords, Rental Agencies & Property Sellers

with

🧑‍💼 Tenants & Property Buyers

INNDOS enables listing management, availability calendars, advanced search, secure messaging, booking visits, property sales inquiries, and full admin moderation.

🔥 1. OWNER / LANDLORD / AGENCY / PROPERTY SELLER PORTAL
Role Name: Owner / Agency / Property Seller
A. Listing Management

Add rental properties

Add properties for sale

Upload photos, videos & documents

Add unit details (bedrooms, bathrooms, amenities, pricing)

Manage availability (renting)

Manage property status (available, occupied, sold, under-offer)

B. Availability Calendar (Rentals)

Select available dates

Block booked dates

Auto synchronization with tenant inquiries

Visual calendar view

C. Inquiry & Messaging System

Receive inquiries from tenants/buyers

Real-time chat system

Document exchange

Schedule viewing/tours

Accept/decline inquiry requests

D. Seller Tools (For Properties Being Sold)

Track buyer interest

Manage offers

Manage negotiation messages

Upload sale documents

E. Owner Dashboard

Total listings

Active rental listings

Properties for sale

Analytics: views, inquiries, conversion

Calendar overview

Notifications

🛠️ TECH STACK FOR INNDOS

Frontend: React + TailwindCSS
Backend: Node.js (Express.js)
Database: MongoDB
Auth: JWT + Role Permissions
Mobile App: React Native (Expo) or Flutter
Real-Time Messaging: Socket.io
Maps: Google Maps API Integration
