---
name: CMS editor pane resizing
description: The CMS editor gives desktop users control over page-list, editor, and live-preview widths.
---

The desktop CMS editor uses bounded, keyboard-accessible vertical splitters so developers can widen the page list or live composition without changing the draft workflow. Mobile remains a stacked layout.

**Why:** The live composition and section editor can contain very different amounts of detail; fixed columns made important content unreadable at common browser widths.

**How to apply:** Keep resize handles visible and discoverable at desktop breakpoints, preserve minimum widths for usable content, and do not let the desktop split-pane behavior force horizontal resizing onto the mobile stacked layout.
