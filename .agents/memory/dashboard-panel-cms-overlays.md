---
name: Dashboard panel CMS overlays
description: Dashboard panel CMS documents customize copy without replacing role-specific tools.
---

Dashboard panel CMS pages are keyed by stable dashboard tab slugs and render published copy above the existing functional panel; they do not replace the panel’s role-gated behavior.

**Why:** Developers need to edit dashboard-facing content without exposing or duplicating owner, host, guest, or admin operations in the CMS.

**How to apply:** Keep the CMS page slug separate from the live hash destination, and preserve the functional dashboard tab as the “Open live panel” destination.
